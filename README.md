# Ashwin R — Portfolio

Dark, single-page portfolio. Plain HTML, CSS, and JavaScript. No build step. No resume page.

## Run it

From this folder:

```bash
py -3 -m http.server 8765
```

Open http://127.0.0.1:8765/

## Files

- `index.html` — page
- `style.css` — dark theme
- `script.js` — slideshow, menu, touch expand
- `public/Ashwin-R-Resume.pdf` — one-page résumé the Download resume control saves
- `RESUME.md` — résumé source, same facts as the PDF
- `public/assets/` — portrait, hero texture, project covers

GitHub Pages serves this repository from the root.
